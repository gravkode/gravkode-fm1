# Расширенные параметры звука — 0.22.0

Версия 0.22.0, после 0.21. ALGO выбирает движок; PRESET — заводской или пользовательский звук (с 0.27 — браузер всех
звуков дорожки по движкам: MANUAL, раздел 9). На странице
звука HOME открывает следующую страницу, после последней возвращает SEQ. **Удерживай HOME и крути SELECT**
для быстрого перехода между страницами; дорожка при этом не меняется. Обычный SELECT выбирает дорожку.

![Анимация реального интерфейса в симуляторе](img/sound-dials.gif)

На экране три небольшие ручки для K1–K3 в духе Octatrack: тонкое кольцо, девять засечек (светлее до значения),
указатель; название сверху, значение снизу; серые и белые; ручка, которую крутишь, чуть подрастает и загорается цветом
темы, потом возвращается. Такие же ручки на SEQ и GLO; нижнего пианино на экране нет. Имя страницы
и её номер сверху. При вращении указатель плавно догоняет значение;
анимируется только полоса ручек, до 30 кадров/с (10 при CPU ≥75%). Иконка движка остаётся компактной сверху.
Сообщения о сохранении и ошибках видны в нижней строке; незаписанный пресет остаётся отмечен до записи.

## Основные и дополнительные ручки

Первая страница сохраняет три основные ручки Plaits. Дополнительные настройки обычных движков начинаются с
**AUTO**: действует прежняя зависимость от основной ручки, поэтому старые звуки остаются без ручных переопределений.
Вращение задаёт отдельное значение; оно имеет приоритет над соответствующей частью основной макроручки. Чтобы вернуть AUTO, прокрути ручку влево за 0. Большинство значений 0–100;
параметры с центральной точкой показывают относительные −50…+50. У FM — исходные диапазоны DX.

Последняя страница синта OUTPUT: TUNE (±25 полутонов, шаг 0,5), LEVEL, AUX MIX. AUX MIX открывает второй выход
модели Plaits: например, второй барабанный синтезатор, субосциллятор FM или альтернативную форму волны.
У барабанных дорожек остаются DRUM и SHAPE, затем OUTPUT: LEVEL, ACCENT (сила возбуждения модели), HOLD
(непрерывное возбуждение, пока клавиша удерживается). Они считают только выбранную барабанную модель.

| FM 2-OP | FINE, PHASE FB, AMP FB, SUB INDEX |
| ANALOG | PULSE, SYNC, SAW SHAPE, SAW LEVEL, SQR LEVEL, AUX SYNC |
| MODAL | DENSITY, CUTOFF, EXCITE Q, ACCENT |

| ADDITIVE | SLOPE, EVEN, ODD |

Под шкалой есть подсказки AUX, WORDS, CLOCK, DIFFUSE: они обозначают нужный выход или режим.
Ручки AUX/ALT/Z и некоторые дополнительные параметры влияют на соответствующий выход или режим: для ALT нужен
AUX MIX, для речевых SPEED/PROSODY — банк слов, для PARTICLE SIZE — включённый DIFFUSE; у CHIPTUNE ARP MODE/RANGE
работают с CLOCK. Это настройки музыкальных моделей; технические константы антиалиасинга остаются внутри DSP.

## 6-OP FM 1 / 2 / 3

Каждый банк получает **57 страниц**: основная, семь общих, по восемь для каждого из шести операторов и OUTPUT.
В них **151 дополнительное поле** звукового патча, без редактора его текстового имени. Нумерация OP 1–6 соответствует
DX: порядок операторов в сохранённых байтах DX обратный.

Общие страницы:

- FM ROUTING: ALGORITHM (1–32), FEEDBACK, KEY SYNC.
- FM MOD: TRANSPOSE, LFO RATE, LFO DELAY.
- FM DEPTH: PITCH MOD, AMP MOD, PM SENSE.
- FM LFO: LFO WAVE, LFO SYNC.
- PITCH RATE / PITCH ENV / PITCH LEVEL: четыре скорости и четыре уровня высотной огибающей.

Страницы каждого оператора:

| Страница | K1 | K2 | K3 |
| --- | --- | --- | --- |
| OSC | LEVEL | COARSE | FINE |
| TUNE | MODE (RATIO/FIXED) | DETUNE | ENABLE |
| RATES | RATE 1 | RATE 2 | RATE 3 |
| ENV | RATE 4 | LEVEL 1 | LEVEL 2 |
| LEVELS | LEVEL 3 | LEVEL 4 | RATE SCALE |
| KEYBOARD | BREAKPOINT | LEFT DEPTH | RIGHT DEPTH |
| CURVES | LEFT CURVE | RIGHT CURVE | VEL SENSE |
| MOD | AM SENSE | — | — |

Четыре RATE/LEVEL — собственная огибающая DX, её значения 0–99, а не миллисекунды классического ADSR.
Начальные значения берутся из выбранного PATCH. Первое изменение создаёт редактируемую копию; следующие правки
обновляют и уже звучащую ноту. **Смена PATCH на основной странице сбрасывает операторные правки** к новому патчу.
Основные BRIGHTNESS и ENVELOPE продолжают действовать как общие макроручки. ENV на отдельной кнопке формирует
внешнюю амплитудную огибающую, как в 0.21.

## Сохранение

Удерживай SAVE, выбери страницу банка через OCT−/+ и белую клавишу для ячейки. Пресет хранит основной звук,
все дополнительные настройки/операторы, OUTPUT и барабанные ручки. Сохраняются все 64 пользовательские ячейки.
Короткий SAVE сохраняет текущие параметры всех восьми дорожек и паттерн. Общие ENV, LFO и FX по-прежнему
хранятся в настройках проекта, за пределами пресета отдельного движка.

Во время игры пресеты ждут в очереди RAM (до восьми разных ячеек; повтор той же ячейки обновляет её в очереди).
Если очередь заполнена, PRESET QUEUE FULL просит остановить воспроизведение, новая ячейка не помечается сохранённой.
Останови секвенсор и отпусти ноты. Пока надпись PRESET PENDING/UNSAVED не сменилась на PRESET SAVED, изменения ещё
не записаны. Ошибка оставляет очередь и прежний записанный звук; короткий SAVE повторяет попытку. Запись может
прервать хвост общего эффекта; обычные настройки проекта лучше сохранять на остановленном секвенсоре.

Формат 0.21 читается автоматически: старые настройки получают AUTO, старый банк пресетов переносится без удаления
исходника. Прерванный перенос продолжается после перезапуска. При PRESET IMPORT FAILED перезапусти прибор;
исходные данные 0.21 остаются на месте.

## Хранилище и проверки

Расширенный пресет занимает 184 байта, включая 164 байта параметров. Новое хранилище — журнал в свободном
окне E5000–ED000, 32 КиБ: 120 записей по 256 байт на 64 ячейки. Последняя страница каждого сектора не используется,
чтобы загрузчик обновления не принял пользовательские байты за свою служебную запись. Заголовок с CRC пишется
последним; при очистке живые записи сначала копируются. В RAM — индекс и очередь, весь банк туда не загружается.
Старый объект DE000/DF000, паттерны, калибровка и адрес настроек остаются на месте. Формат настроек — прежние
92 байта плюс восемь блоков параметров, всего 1404; старые версии читают знакомый префикс.

Проверки: 13 сценариев симулятора, перенос 0.21 и перезапуск с параметрами всех шести операторов; 96 проверок
влияния дополнительных ручек на звук; соответствие всех 151 поля FM и правки удерживаемой ноты; крайние значения;
1008 сравнений одного/двух ядер с FX и восемью дорожками; повреждение/прерывание записи, очистка журнала, износ,
резервная страница загрузчика, сохранение прежних данных. Сборка для прибора прошла проверки памяти и кода; реальное
прослушивание и CPU/XRUN при интенсивном вращении ручек ещё нужно проверить на FM-1.
